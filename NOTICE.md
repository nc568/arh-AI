# Сторонние материалы и благодарности

## Gated DeltaNet-2 (статья)

Этот проект реализует архитектуру из статьи:

> Ali Hatamizadeh, Yejin Choi, Jan Kautz. **Gated DeltaNet-2: Decoupling Erase
> and Write in Linear Attention.** arXiv:2605.22791, 2026.
> https://arxiv.org/abs/2605.22791

Статья доступна по лицензии CC BY 4.0 (проверяйте актуальные условия на arXiv).
В этом репозитории пересказаны только уравнения и архитектурные идеи из статьи;
полный текст статьи не включён.

## Официальная реализация NVIDIA

Официальный код: https://github.com/NVlabs/GatedDeltaNet-2 — распространяется под
**NVIDIA Source Code License-NC** (только некоммерческие исследования/оценка, с
требованиями к уведомлениям при распространении производных работ).

**Код из этого репозитория НЕ копировался в данный проект.** Все модули в
`gdn2lab/` написаны независимо на чистом PyTorch по уравнениям из статьи.
Triton-ядра (`chunk_gdn2.py`, `fused_recurrent_gdn2.py`) не используются.

Если вы планируете коммерческое использование или хотите использовать
официальные оптимизированные ядра — изучите лицензию NVIDIA и подключите
официальный репозиторий самостоятельно.

## Используемые библиотеки

- PyTorch (BSD-3-Clause), torch-xla (Apache-2.0) — обучение.
- `tokenizers` (Apache-2.0), `safetensors` (Apache-2.0), `numpy` (BSD-3-Clause).
- `gguf` (MIT) — запись/чтение GGUF и квантование.
- `litert-torch`, `ai-edge-litert`, `ai-edge-quantizer` (Apache-2.0) —
  конвертация в `.tflite` и post-training квантование.
- `bitsandbytes` (MIT) — опциональный AdamW8bit.

## Дисклеймер про результаты

Рецепт статьи (1.3B параметров, 100B токенов FineWeb-Edu, 0.5M токенов в
батче) **не воспроизводится** в бесплатном Colab. Этот проект предназначен для
обучения маленьких моделей (≈1–80M параметров) с нуля в учебных и
исследовательских целях. Заявленные в статье метрики качества здесь не достигаются.
